# Changelog

## 0.4.0

- Introduced the native C++20 and Qt 6 dashboard.
- Added a dedicated D-Bus hardware monitoring backend.
- Added a KDE Plasma 6 widget.
- Implemented asynchronous hardware readings through the QML bridge.
- Added CPU usage and NVIDIA GPU temperature monitoring.
- Added performance profile switching through D-Bus.
- Added dashboard launching directly from the Plasma widget.
- Improved NVIDIA monitoring process cleanup.
- Added an isolated Arch Linux packaging workflow.


## 0.3.0
- Package from a versioned, SHA-256-verified source tarball
- Retain Qt 6 GUI, CLI, Polkit helper, and notification service from 0.2.1
- Document compatibility and installation
